# 계층 world model의 목표 비용 공간 반경: 사전 등록

작성 2026-10-07. 실행 전에 커밋한다. CPU만 쓰고(램 14GB, 순차 실행), GPU는 쓰지 않는다.
latent는 모두 `preprocess.py` 경로로 계산한다. 결과는 `HIERARCHY_GEOMETRY.md`에 단계마다 커밋한다.

## 주장 후보

> 계층적 world model은 예측 지평은 늘리지만, 목표 비용을 재는 거리의 반경은 L1 학습 rollout 규모(약 2칸)에 그대로 갇혀 있다.

이 문서의 기준값(이미 측정한 값, LATENT_LAW A2, 학습된 L1 obs latent, 튐 제외):
R_xy = 1.35칸, R_maze = 2칸, d = 2 중앙값 θ = 0.587이다. V0 hard 인스턴스의 시작 미로 거리는 중앙값 13칸(7–17)이다.

## 1. 코드 확인 (가장 먼저)

`pldm/` 코드에서 파일과 줄 번호로 다음을 정리한다.
- (a) L2 플래닝의 목표 비용이 계산되는 표현 공간(L1 obs latent인지, L2 전용 표현인지, 투영이 있는지).
- (b) L2 predictor의 입력·출력 상태, L2 학습 rollout 길이, L2 한 스텝에 해당하는 L1 스텝 수와 그에 해당하는 실제 이동량(칸).
- (c) L2 전용으로 학습된 인코더나 표현이 있는지.

**판정 규칙**:
- 목표 비용이 L1 obs latent(또는 그것의 항등 변환)에서 계산되면 "주장 후보 성립 가능"으로 보고 2단계로 간다.
- L2 전용 학습 표현이 있으면 2단계에서 그 표현의 반경도 측정한다.
- 비용 공간이 L1 obs latent와 같은 텐서라면(항등 인코더), 2단계의 L2 비용 공간 반경은 **정의상 A2의 값과 같다**. 이때는 재계산으로 그 동일성만 확인하고, 수치를 다시 해석하지 않는다.

## 2. L2가 쓰는 표현의 포화 반경

LATENT_LAW A2와 같은 프레임(맵당 400개, 시드 0), 같은 쌍, 같은 반경 정의(90% 상승점, 튐 제외가 주 분석)를 쓴다.

**예측 (수치 고정)**:
- **P2a**: L2 비용 공간의 R_xy ∈ [0.8, 1.25] × 1.35 = **[1.08, 1.69]칸**이다(L1과 같은 반경).
- **P2b**: L2 비용 공간의 R_maze ≤ 0.25 × 13 = **3.25칸**이다(평가 과제의 시작 거리보다 훨씬 작다).
- **P2c**: R_xy < (L2 **학습** rollout이 닿는 이동량의 xy 중앙값)이다. L2 학습 rollout = `l2_n_steps × l2_step_skip` L1 스텝(1(b)에서 확정)이고, 이동량은 r50에서 잰다.
- **P2d**: R_maze ≤ 0.25 × (L2 **계획** 지평이 닿는 범위)이다. 계획 지평은 hard 평가에서 최대 47 L2 스텝(470 L1 스텝)이고,
  범위는 V0 성공 시행의 평균 속도 0.111칸/스텝 × 470 = 52칸으로 환산한다. 기준은 13칸이다.

주장 후보 판정: P2a, P2b, P2d가 모두 맞으면 "**지지**", P2a가 틀리면(L2 비용 공간 반경이 L1과 다르면) "**기각**", 나머지는 "**부분 지지**"다.
P2c는 보조로 보고한다. P2c가 틀리면, 학습 rollout 자체도 멀리 닿지 않는다는 뜻이므로(무작위 데이터의 확산이 느림) 해석을 따로 단다.

## 3. 확산 스케일링

- n = 3, 5, 10, 14, 20, 30, 40, 80, 160 스텝 이동량: xy 중앙값, xy 90%, BFS 중앙값.
- r50 에피소드는 101프레임이라 n ≤ 100만 r50에서 구한다.
  n = 160은 r50과 같은 생성기와 설정(무작위 i.i.d. 행동, action_repeat 4)으로 같은 미로와 시작에서 **200스텝 무작위 행동 시뮬레이션**을 Kaggle CPU 커널로 만들어 구한다.
  앞서 100스텝 시뮬레이션이 r50 통계를 재현한다는 것을 확인했다. 시뮬레이션에서 n ≤ 100도 함께 구해 r50과 맞는지 확인한다.
- log(이동량 중앙값) 대 log(n)의 기울기 α를 n ∈ {20, 30, 40, 80}에서 최소제곱으로 맞춘다. **√n 스케일링이면 α ≈ 0.5**다.
  예측: 짧은 n(≤ 10)은 관성 때문에 α > 0.5(탄도 운동에 가까움)이고, 긴 n은 0.5 근처이며, 미로 크기 때문에 큰 n에서는 꺾인다.
- **외삽 (명시적 외삽)**: 반경이 14스텝 이동량에 비례한다고 가정한다(R_xy / D14 = 1.35 / 0.722 = 1.87, LATENT_LAW A의 결과에서 나온 비율).
  그러면 반경 15칸을 얻으려면 이동량 중앙값 15 / 1.87 ≈ 8.0칸이 필요하다.
  긴 n 구간에서 맞춘 거듭제곱 법칙 D(n) = c·n^α로 필요한 n을 계산한다. 미로 경계와 벽은 무시하는 외삽이라는 점을 명시한다.

## 4. 오프라인 비용 비교: 거리 합 대 처음 닿는 시점

- V0 로그에는 L2 후보 궤적이 저장돼 있지 않다(`diag_recorder.py`는 웨이포인트 1, 2의 디코딩 좌표와 비용 요약만 저장).
  그래서 V0 재계획 시점에서 학습된 L2 predictor를 CPU에서 굴려 후보를 만든다.
- **표본**: Stage 1 재계획 중 300개를 무작위로 고른다(시드 0, 성공과 실패 시행에서 비례 추출). CPU 시간 때문이다.
- **상태**: 이미 렌더링한 V0 재계획 이미지를 평가 경로로 인코딩한다. 속도는 직전 두 위치 차이 × 25.6이다(앞선 분석과 같음).
- **후보**: K = 200개(V0 `level2.mppi.num_samples`)를 뽑는다. z ~ N(0, 10·I)를 [p2 + 0.1, p98 − 0.1]로 clamp하고(V0 탐색 분포, nominal U = 0인 첫 반복에 해당), 지평 T는 그 재계획의 실제 L2 `plan_size`다.
- **비용**:
  - (a) 현재 비용 = Σ_{t=1..T} MSE(예측 obs_t, 목표 obs latent)(V0와 같은 합산 방식).
  - (b) 처음 닿는 시점 = MSE ≤ θ = 0.587이 되는 첫 t, 못 닿으면 T + 1이다. 동률이면 (a)가 작은 후보를 고른다.
- **평가**: 각 비용으로 고른 후보의 웨이포인트 1(`pred_obs[1]`)을 진단용 위치 prober로 디코딩하고, 미로 걸음 수 변화 Δ = d(에이전트) − d(웨이포인트 1)를 잰다(양수면 목표 쪽).
  - 주 지표: 뒤쪽 웨이포인트(Δ < 0) 비율, Δ 평균.
  - 비교: 같은 재계획 짝 단위로, 뒤쪽 여부는 McNemar 정확검정, Δ는 Wilcoxon 부호순위 검정(양측).
  - 보조: 후보 중 하나라도 θ 안에 닿은 재계획의 비율.
- **예측**: (b)가 (a)보다 뒤쪽 비율이 낮고 Δ가 크다.
  근거는 "포화 반경 밖에서는 거리 합이 거의 상수라 비용 차이가 잡음이고, 처음 닿는 시점은 반경 안의 정보만 쓴다"는 것이다.
  단 θ 안에 닿는 후보가 없는 재계획에서는 (b)가 (a)와 같아진다(동률 처리). 그래서 효과는 닿은 재계획에 한정될 것으로 예측하고, 닿은 재계획만의 결과도 따로 보고한다.
