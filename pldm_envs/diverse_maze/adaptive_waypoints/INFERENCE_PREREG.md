# 추론 설계 민감도 연구: 사전 등록

작성일 2026-10-05. GPU 실행 전에 커밋한다. 코드 근거는 `INFERENCE_LOOP.md`에 있다.
학습(미세조정)은 하지 않는다. 모든 GPU 평가는 원논문 사전학습 계층 체크포인트로 한다:
`seungwonryoo/hwm-finetune-checkpoints`의 `pretrained_baseline.ckpt`, §6b baseline n=120과 같은 파일, `load_l1_only=false`.

## 1. 공통 평가 설정

- 인스턴스: hard(D13–16) 120개. `starts_targets_13_16.pt`(seed=42) 40개 + `extra80_full.pt`(seed=20260910) 80개.
  §6b/§9와 같은 순서이고, 20개씩 6 chunk로 나눈다.
- 설정: §6b/§9 hard 평가와 같다. `hard.n_steps=500`, `hard.level2.mppi.num_samples=200`, `l2_latent_bounds_percentile=2.0`,
  `replan_every=4`, L1 K=1000 등. 변형마다 바꾸는 값만 아래에 명시한다.
- **시행 단위 난수 고정(CRN)을 모든 실행에서 켠다**(1단계에서 구현). 환경과 재계획마다 `(seed, trial_id, stage, step, level)`로
  `torch.Generator`를 만들고, MPPI 잡음과 초기 U를 이 생성기로 뽑는다. 그러면 V0과 변형이 같은 인스턴스·같은 시점에 같은 난수를 받는다
  (짝지은 비교의 분산 감소).

## 2. 실행과 비교 쌍

| ID | 내용 (V0 대비 변경점) | 우선순위 |
|---|---|---|
| V0 | 기준. 변경 없음 (CRN on) | – |
| V1 | `eval_cfg.l2_use_latent_mean_std=true` (L2 탐색 분포를 데이터 통계로) | 1 |
| V2 | `replan_every=8` | 2 |
| V3 | `replan_every=2` | 3 |
| V4 | L1 목표 `pred_obs[2]`, L1 계획 길이 20 (코드 플래그). L1은 15프레임(14스텝 rollout)으로 학습됐으므로 20스텝은 학습 범위 밖 | 4 |

비교 쌍은 V1–V0, V2–V0, V3–V0, V4–V0의 4개다. 변형끼리는 비교하지 않는다(탐색적 기술 통계로만 보고).

## 3. 주 지표와 검정

1. **성공률**: 정확 McNemar 검정(불일치 쌍에 대한 이항검정, 양측). 방향별 뒤집힘 개수를 함께 보고한다
   (V0 실패→변형 성공, V0 성공→변형 실패).
2. **스텝 수**: 두 조건이 모두 성공한 인스턴스에서 첫 보상 스텝(MPC 스텝)으로 Wilcoxon 부호순위 검정(양측, 0 차이는 `zero_method="wilcox"`).
- **다중 비교 보정**: 지표마다 V0 대비 4개 비교에 Holm 보정을 따로 적용한다(성공률 4개, 스텝 수 4개). α=0.05.
  실행하지 못한 변형(할당량 규칙으로 건너뜀)은 m에서 빼지 않는다. 즉 m=4로 고정하고 결측은 "미실행"으로 표시한다(보수적).
- 보조: Wilson 95% 구간, 성공 시행 평균·중앙값 스텝.

## 4. 사전 예측 (사용자 제시, 그대로 기록)

- V1: L2 clamp 비율이 크게 줄고, 성공률이 V0 이상.
- V2: 흔들림 유형 실패가 줄지만, 정체 유형은 늘 수 있음.
- V3: V0와 비슷하거나 흔들림이 늘어남.
- V4: 직선 통로가 많은 인스턴스에서는 스텝 수 감소, 갈림길이 많은 인스턴스에서는 실패 증가.

분석자 메모 (예측을 바꾸지 않고 사전에 기록만 함): `l2_use_latent_mean_std=true`이면 노이즈 표준편차가
`l2_latent_std × noise_sigma(=10)`가 된다(`mppi_planner.py:309-326`). CPU 추정 posterior std는 0.4–1.6이므로 표준편차가 4–16이 되고,
현재(√10≈3.2)보다 커진다. 평균 이동(u_init=데이터 평균)은 있지만, 코드만 보면 clamp 비율은 **늘어날** 가능성이 높다. 결과로 판정한다.

V4의 "직선 통로가 많은/갈림길이 많은 인스턴스" 판정: 시작–목표 BFS 최단 경로가 지나는 셀 중 갈림길 셀(열린 이웃 ≥3)의 비율로
120개를 중앙값 기준 두 그룹으로 나눈다.

## 5. 기록 항목 (모든 실행, 재계획 시점마다, 시행별 파일)

에이전트 xy, 목표 xy, 웨이포인트 1의 디코딩 xy(아래 prober), 웨이포인트 1의 벽 셀 여부(분석 단계에서 `grid_utils`로 판정),
L1 최종 비용(L1 nominal rollout 마지막 스텝의 obs MSE와 웨이포인트 1 사이), L2 최선 비용(샘플 중 최소 총비용),
직전 재계획 대비 웨이포인트 1 이동량(obs 잠재 MSE와 디코딩 xy 거리), L2·L1 MPPI 유효 표본 수 1/Σω²,
L2 샘플에서 clamp된 차원 비율, 그리고 매 MPC 스텝의 에이전트 xy.
BFS 미로 거리(셀)는 저장한 xy와 지도로 분석 단계에서 계산한다.

**위치 prober**: 평가 모드에서 플래너가 받는 prober는 학습되지 않은 무작위 초기화 상태다
(`pldm/probing/evaluator.py:272-273`, `train_probers=eval_l1=false`). 그래서 디코딩용 위치 prober를 따로 학습한다.
모델 가중치는 동결하고, 같은 구조(`conv`/`c`, 입력 obs_component 16×43×43)를 r50 probe split의 실제 인코딩으로 CPU에서 학습한다.
모델 미세조정이 아니라 진단용 선형계 학습이다. 검증 오차를 함께 보고하고, 예측 잠재(pred_obs)에 적용할 때 분포 밖일 수 있다는 한계를 명시한다.

## 6. 실패 유형 정의 (실패 시행만, 중복 허용)

d(t) = 에이전트 셀에서 목표 셀까지 BFS 미로 거리(셀), t = MPC 스텝(0..484). 재계획 r의 웨이포인트 1 디코딩 좌표를 w_r이라 한다.
한 셀 크기 g = 0.987(환경 단위).

- (a) 정체: min_{t∈[385,484]} d(t) > d(384) − 1. 즉 마지막 100스텝 동안 1셀 이상 줄지 않음.
- (b) 흔들림: 이동 벡터 Δ_r = w_r − w_{r−1}이 "크다"는 것은 ‖Δ_r‖ > 1g를 뜻한다.
  연속된 두 큰 이동 사이의 cos(Δ_r, Δ_{r'}) < −0.5이면 "뒤집힘"이다. Stage 1 재계획 중 뒤집힘 횟수가 10% 이상이고 5회 이상이면 흔들림.
- (c) 도달 불가 당근: Stage 1 재계획 중 30% 이상에서 (w_r이 벽 셀 안) 또는 (L1 최종 비용 > 성공 시행 전체 재계획 L1 최종 비용의 90번째 백분위수).
- (d) 잘못된 경로: max_t [d(t) − min_{s≤t} d(s)] ≥ 3.
- (e) 느린 진전: d(484) ≤ d(0) − 1이고, Spearman(t, d(t)) < −0.5이고, (a)와 (d)가 아님.
- 어느 것에도 해당하지 않으면 "미분류".

## 7. 조기 경고 신호

신호마다 Stage 1 재계획 중 t < 100인 값의 시행별 평균(L1 최종 비용, 웨이포인트 1 이동량 두 종류, L2/L1 유효 표본 수, clamp 비율)을 구해
실패 판별 AUROC를 계산한다(V0, 120개). 방향은 사후에 고르지 않고 AUROC를 그대로 보고한다(0.5 미만이면 반대 방향이 예측력).

## 8. 1단계 검증 기준

같은 20개 인스턴스(1번째 chunk)를 chunk 크기 20과 10(10개씩 2회)으로 평가한다.
20개 전부에서 성공 여부와 스텝 수가 같으면 통과다. 다르면 남은 잡음원을 기록하고 CRN을 켠 채 계속한다.
